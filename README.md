# 王秀睿的个人网站

王秀睿 · AI 产品经理的个人网站。采用 XR OS 桌面窗口式布局，包含个人介绍、个人项目、工具与技能、文章和联系入口，适配桌面和手机。

这是纯 HTML、CSS 和 JavaScript 项目。`dist/` 内的文件就是完整可编辑源码，直接部署即可，无需安装依赖或构建。

## 预览

在本目录运行 `python3 -m http.server 4173 --directory dist`，访问 http://localhost:4173 。也可以直接打开 `dist/index.html`。

## 替换内容

- `dist/profile.js`：个人资料、头像路径、联系方式、项目、资源与文章。空头像使用 XR 缩写占位；空联系方式展示待补充提示。
- `dist/index.html`：五个连续章节与整体框架。
- `dist/app.js`：滚动目录联动、卡片轮播、资源链接和详情交互。
- `dist/details.js`：项目与文章详情，包含明确标注的预置示例。请用实际经历和正式文章替换。
- `dist/styles.css`：配色与响应式排版。
- `dist/resources/`：可下载的产品拆解、用户访谈和 AI 产品评估 Markdown 模板。

网站没有后台、数据采集或表单服务。联系按钮在配置邮箱后调用访客邮件客户端。

## 发布到 GitHub Pages

`.github/workflows/pages.yml` 会在推送到 `main` 后，自动将 `dist/` 发布到 GitHub Pages。发布产物顶层包含实际的 `index.html`。

在仓库的 Settings → Pages → Build and deployment 中，将 Source 设为 GitHub Actions。实际访问链接以 Pages 设置页或成功部署任务的结果为准。

网站使用相对资源路径，支持个人主页域名和仓库子路径。使用系统字体，不依赖外部字体服务。部署不需要任何自定义密钥。

## 视觉设计

框架参考 [MN OS 个人主页](https://mn0709.github.io/#about)：顶部窗口栏、固定左栏、右侧内容区、浅蓝灰底色及横向卡片展廊。使用自己的姓名、资料和内容，未使用参考作者的肖像、个人履历或作品资产。

五个章节始终存在于同一正文滚动容器中。上下滚动正文时，左侧目录自动高亮并同步地址中的章节锚点；在左栏上滚轮也会滚动正文。目录链接可作辅助定位，但不切换或隐藏章节。手机端目录变成横向栏，并自动将当前栏目移入可见范围。

项目、资源和文章展廊支持按钮、左右方向键、横向触控板和触摸滑动；竖向手势保持用于浏览正文。减少动态效果设置生效时停用过渡动画。旧的 `#home`、`#work`、`#notes` 锚点仍可定位到对应章节。
